# Reading Log

The Reading Log records each reading independently of the library file and Reading Queue. Use it to track ebook, print and other-app reading sessions.

- Records can be **In progress**, **Finished** or **Abandoned**. Each record can include dates, a rating, a review and reading time.
- A completed reread creates a separate record. Continuing an abandoned reading keeps its history; starting over creates another entry.
- Filter and sort the log, or use manual ordering where available. Removing a library file leaves its reading history and saved annotations intact.
- DATA and FULL backups include log entries and covers. Restoring a DATA archive keeps the history while omitting book files.

The Reading Log is stored locally and does not sync between devices. Its saved history is separate from book-file availability.
