# Frog Reader BETA 2 — upstream release record

**2026-10-17 · Android 8.0+ · versionCode 6 · GPL-3.0-only**

This archived note records the upstream Frog Reader BETA 2 release by KNITIPKA. It describes that upstream build, not a GOAT Reader release.

## Highlights

- Improved reader performance, typography, custom-font handling and SVG/image rendering.
- Refined text selection, Quotes & Bookmarks, settings, reader controls and library transitions.
- Added external text actions and dedicated TXT/Markdown reading defaults.

## Limitations

PDF, KFX, DRM-protected books, full fixed-layout EPUB/KF8, vertical writing, and embedded audio/video are unsupported. EPUB CSS, MathML and ruby support are bounded subsets. The active EPUB reader has additional feature and conformance work in progress; see the [EPUB 3.3 status](../epub33-reading-systems-conformance.md).

## Verification record

The original BETA 2 release checks and test counts apply to that tagged build only. Current verification instructions are in the [build guide](../build-quality.md) and [release guide](../releasing.md). See the [changelog](../../CHANGELOG.md) for the recorded feature history.
