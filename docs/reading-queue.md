# Reading Queue

The Reading Queue is a manually ordered list for books you plan to read. It is available from **Profile → Reading Queue**.

- Add a title and optional author or note. Drag the handle to change its priority; the first entry is **Up next**.
- Attach a supported book file to an entry. The attachment stays with the queue item until you choose **Start reading**, which imports it into the library and removes the queue item.
- Entries without an attached file can remain as reading plans. Add a file later or remove the entry.
- Undo restores a recently removed entry and its position. Editing a title or note keeps the queue order.
- DATA and FULL backups preserve queue entries. FULL backups also include attached files; DATA restores entries without ready-to-open files.

The queue is stored on-device and does not synchronize to a cloud service. See [backup and restore](../README.md#features) for the app's current backup scope.
